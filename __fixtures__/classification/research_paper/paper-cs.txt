Efficient Attention Mechanisms for Long-Context Language Models

Abstract
Transformer-based language models have achieved remarkable performance across natural language processing tasks, but their self-attention mechanism scales quadratically with sequence length, limiting their effective context window. We propose Sparse Cascade Attention (SCA), a novel attention architecture that reduces computational complexity from O(n²) to O(n log n) while maintaining 98.7% of dense attention quality on standard benchmarks. SCA combines learned routing gates with a hierarchical attention cascade that processes tokens in coarse-to-fine passes. We evaluate SCA across language modeling, retrieval-augmented generation, and long-document summarization tasks, demonstrating consistent improvements in both throughput and quality at context lengths of 32K, 64K, and 128K tokens.

1. Introduction
The self-attention mechanism (Vaswani et al., 2017) enables transformer models to capture long-range dependencies, but its computational cost grows quadratically with sequence length. Recent approaches to this problem include sparse attention patterns (Child et al., 2019; Zaheer et al., 2020), linear attention approximations (Katharopoulos et al., 2020), and state-space models (Gu et al., 2022). While effective, these methods either sacrifice attention quality or require specialized hardware.

We observe that in long-context scenarios, not all token pairs require fine-grained attention. Many interactions can be adequately captured through coarser representations. Motivated by this, we propose Sparse Cascade Attention, which processes tokens through multiple resolution levels, allocating more computation to token pairs that benefit from fine-grained interaction.

2. Method
2.1 Problem Formulation. Given an input sequence X ∈ R^(n×d), standard multi-head attention computes A = softmax(XQ·XK^T / √d)·XV, where the attention matrix has O(n²) entries.

2.2 Cascade Architecture. SCA operates in L=3 resolution levels. At level l, the sequence is partitioned into blocks of size 2^l·B, where B is the base block size (typically 64 tokens). Within each block, we compute full dense attention. Between blocks, a learned routing mechanism selects the top-k most relevant blocks for cross-block attention at the next finer level.

2.3 Routing Gate. The routing gate is a lightweight cross-attention module R(X_i, X_j) = σ((W_r·X_i)·(W_r·X_j)^T), where σ is the sigmoid function. The top-k gates are selected per query token to determine which blocks receive fine-grained attention in the next level.

3. Experiments
3.1 Language Modeling. We trained 7B-parameter models with SCA and dense attention on 2T tokens from the RedPajama dataset. On the standard perplexity benchmarks (WikiText-103, PG-19), SCA-7B achieved perplexities of 8.42 and 5.91, compared to 8.38 and 5.87 for dense attention—a gap of only 0.48%.

3.2 Long-Context Tasks. On the LongBench evaluation suite (Bai et al., 2023), SCA-7B outperformed similarly-sized dense models by 3.2% on average across retrieval, summarization, and coding tasks at 32K context length.

3.3 Efficiency. SCA reduced peak GPU memory usage by 62% at 128K context length on a single A100-80GB GPU and achieved 3.4x faster inference throughput compared to FlashAttention-2.

4. Related Work
Efficient attention has been extensively studied. Longformer (Beltagy et al., 2020) uses fixed sparse patterns. Reformer (Kitaev et al., 2020) employs locality-sensitive hashing for approximate attention. Our approach differs by using learned routing that adapts to input content.

5. Conclusion
Sparse Cascade Attention offers a practical solution for scaling transformer context windows without significant quality degradation. Future work includes extending SCA to multimodal models and exploring dynamic routing strategies.
