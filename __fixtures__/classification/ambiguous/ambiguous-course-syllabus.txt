COURSE DESCRIPTION

This project-based course bridges the gap between data science theory and practice. Students will work in teams of 3-4 on a real-world data science project sourced from industry partners (Amazon, Zillow, and the Fred Hutchinson Cancer Center). The course covers the full data science lifecycle: problem formulation, data acquisition and cleaning, exploratory analysis, feature engineering, model selection and training, evaluation, and deployment.

LEARNING OBJECTIVES

Upon completion of this course, students will be able to:
- Formulate a data science problem from a vague business or research question
- Acquire, clean, and validate data from multiple sources (APIs, databases, web scraping)
- Apply appropriate statistical and machine learning methods to real-world datasets
- Evaluate models using rigorous methodologies (cross-validation, statistical significance testing)
- Communicate findings through data visualization and technical writing
- Deploy a trained model as a REST API endpoint

PREREQUISITES
- CSE 416 (Introduction to Machine Learning) or STAT 435
- Proficiency in Python (pandas, scikit-learn, matplotlib)
- Basic SQL

REQUIRED TEXTS
- "Python for Data Analysis" by Wes McKinney (3rd ed., O'Reilly, 2022)
